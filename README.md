# `rusti-graben`

> A strict, zero-drift quality-hygiene template and migration framework for Rust repositories.

## Available tasks

Tasks are generated from `./mk --list` (do not hand-maintain this list):

```bash
./mk --list
```

## Quick Start

```bash
./mk setup
./mk ci
```
