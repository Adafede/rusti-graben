# Code of Conduct

All contributors and maintainers participating in issues, pull requests, and reviews are expected to keep interactions respectful and constructive.

## Expected Behavior

- Focus technical feedback on code, gates, reproducibility, and documentation clarity.
- State evidence and reproduction steps when challenging a change or gate rule.
- Welcome newcomers adopting or contributing to the repository.

## Unacceptable Behavior

Harassment, personal attacks, insults, discriminatory language, or publishing private information is unacceptable and may be addressed by repository maintainers removing comments or restricting access.
